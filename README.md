## 一、STM32 串口通信—— 轮询、中断、DMA 三种实现方式对比

### 1.1 任务概述

在 STM32F103C8T6 最小系统板上，通过 USART1 与上位机（Windows 10）进行串口通信，实现以下功能：

1. **持续发送**：STM32 通过串口连续向上位机发送字符串 `hello windows!`，上位机用"串口助手"工具接收显示；
2. **暂停/继续控制**：上位机向 STM32 发送字符 `#` 时，STM32 暂停发送；发送字符 `*` 时，STM32 恢复继续发送。

### 1.2 串口通信参数

| 参数     | 设置值                                            |
| -------- | ------------------------------------------------- |
| 串口外设 | USART1                                            |
| 引脚     | TX = PA9，RX = PA10                               |
| 波特率   | 115200                                            |
| 数据位   | 8 Bits                                            |
| 校验位   | None（无校验）                                    |
| 停止位   | 1 Bit                                             |
| 帧格式   | 起始位(1) + 数据位(8) + 停止位(1)，共 10 bit/字节 |

## 二、串口通信基础

### 2.1 UART 串口协议

- **异步通信**：无独立时钟线，收发双方预先约定相同波特率；
- **帧结构**：起始位 + 数据位 + 校验位(可选) + 停止位；
- **全双工**：收发可同时进行；
- 接线规则：TX 接对方 RX，RX 接对方 TX，**必须共地 GND**。

### 2.2 HAL 库架构

CubeMX 生成工程后，main.c 提供一条固定流水线：

```
上电 → 启动文件(.s) → SystemClock_Config(72MHz)
     → MX_GPIO_Init → MX_USART1_UART_Init → while(1) 主循环
```

我们**只需在 `/* USER CODE BEGIN xxx */` 与 `/* USER CODE END xxx */` 标记之间**添加代码，不能改动 CubeMX 自动生成的函数。

### 2.3 对应 HAL 函数

| 动作 | 轮询(阻塞)          | 中断                   | DMA                     |
| ---- | ------------------- | ---------------------- | ----------------------- |
| 发送 | `HAL_UART_Transmit` | `HAL_UART_Transmit_IT` | `HAL_UART_Transmit_DMA` |
| 接收 | `HAL_UART_Receive`  | `HAL_UART_Receive_IT`  | `HAL_UART_Receive_DMA`  |
| 延时 | `HAL_Delay`         | —                      | —                       |

## 三、小结
三种方式（轮询、中断、DMA）都成功实现"持续发送 `hello windows!` + `#` 暂停 / `*` 继续"的串口通信功能；**轮询方式**简单直观，适合低频简单通信，但 CPU 被阻塞；**中断方式**非阻塞，CPU 利用率提高，实时性好，是嵌入式最常用方式；**DMA 方式**数据搬运由硬件完成，CPU 利用率最高，适合大批量高速数据传输，但配置较复杂。
